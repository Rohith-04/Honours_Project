# Interconnect — Interface Documentation

Core: `rtl/interconnect/` (Forencich `axi_interconnect` + `arbiter` +
`priority_encoder`, `S_COUNT`/`M_COUNT` parameterized, active-high `rst`).
Wrapper: `rtl/interconnect/axi_interconnect_wrap_1x4.v`, generated by
`scripts/axi_interconnect_wrap.py -p 1 4 -n axi_interconnect_wrap_1x4`
(tracked RTL; one manual fix documented below).

## Configuration (baseline)

| Port | Slave | Base           | Width  | Size |
|------|-------|----------------|--------|------|
| m00  | RAM   | `0x0000_0000`  | 16 bit | 64 KiB |
| m01  | UART  | `0x1000_0000`  | 12 bit | 4 KiB |
| m02  | Timer | `0x1001_0000`  | 12 bit | 4 KiB |
| m03  | GPIO  | `0x1002_0000`  | 12 bit | 4 KiB |

Single master s00 (VeeR-side at Level 3, BFM at Levels 1–2).
`DATA_WIDTH = 32`, `ADDR_WIDTH = 32`, **`ID_WIDTH = 12`**.

## Notes

- The generator template hardcodes `ID_WIDTH = 8`; the tracked wrapper
  has the one-line fix to 12 (matches UART IP + `soc_pkg`). If the
  wrapper is ever regenerated, re-apply it.
- Base addresses/widths are overridden from `soc_pkg` at instantiation
  in `honours_soc.sv` — never edited into the generated file by hand
  beyond the ID fix.
- Unmapped addresses complete with **DECERR (`2'b11`)** on both read and
  write paths (verified in core source) — the integration test asserts
  exactly this, including just-past-RAM (`0x0001_0000`).
- The core serializes through one FSM (no concurrent multi-master
  throughput at `NUM_MASTERS = 1` this is unobservable). Adding the NDA
  later is a parameter bump + port connection, not a rewrite.
- Reset into the wrapper is active-high `rst`, derived by inversion from
  `aresetn` at the `honours_soc` boundary (reset convention).
- **Single-beat slaves need RLAST tie-offs.** UART/Timer/GPIO expose no
  RLAST; `m_axi_rlast[1..3]` are tied to `1'b1` in `honours_soc.sv` (every
  beat is last). The core retires reads only on RLAST — floating it parks
  the FSM in STATE_READ after the first peripheral read (see
  `doc/verification/debug.md`). Any future single-beat slave needs the
  same tie-off; only burst-capable slaves (RAM) drive RLAST themselves.
- Grant stability: the arbiter (`arbiter.v`, BLOCK_ACK) must hold a
  granted request until acknowledge — the hold body was once accidentally
  dropped, misdirecting every read into WRITE at DECODE. The core samples
  direction live, so a dropped grant corrupts the very next cycle.
